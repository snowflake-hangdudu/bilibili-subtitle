B站字幕提取与整理助手 · 隐私政策

最后更新：2026-08-23 · 版本 1.0.0 · 常见问题

我们处理什么数据

  • 当前 B 站视频的公开信息（标题、BV/AV、分 P、UP 名）
  • 该视频已经提供的字幕轨道和字幕文本
  • 你在扩展里选择的导出格式、文件名模板等设置

数据如何处理

  • 字幕提取、清洗、搜索、复制和导出都在本地浏览器中完成
  • 不会把字幕正文、视频内容或浏览记录上传到开发者服务器
  • 可能读取公开配置接口，仅用于公告、开发合作文案和评分开关
  • V1 没有账号系统，也没有云同步

权限为什么需要

  • storage：记住导出偏好和本地评分状态
  • downloads：保存 TXT / SRT / Markdown
  • B 站与字幕 CDN：识别视频并读取已公开字幕
  • 配置站：读取公告、合作与评分开关，不含字幕正文
