# 隐私说明

产品名称：B站字幕提取助手  
版本：1.0.0  
日期：2026-08-24

## 我们处理什么数据

- 当前 B站视频的公开信息（标题、BV/AV、分P、UP 名）
- 该视频已经提供的字幕轨道和字幕文本
- 你在扩展里选择的导出格式、文件名模板等设置

## 数据如何处理

- 字幕提取、清洗、搜索、复制和导出都在本地浏览器中完成
- 不会把字幕正文、视频内容或浏览记录上传到开发者服务器
- 可能读取公开配置接口，仅用于公告、开发合作和评分开关
- V1 没有账号系统，也没有云同步或在线分享
- 导出文件只在你主动点击后，写入浏览器允许的下载位置

## 权限为什么需要

- `storage`：记住导出偏好，避免每次重设
- `downloads`：保存 TXT / SRT / Markdown
- `clipboardWrite`：工作台复制字幕文本
- B站与字幕 CDN 访问：读取当前视频页和字幕接口；不访问其他网站

## 清理

打开扩展「设置」页，可一键清理本机保存的设置和最近一次字幕结果。
